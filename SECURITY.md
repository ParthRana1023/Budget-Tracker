# Security Policy

## Supported Versions

SaveFirst receives active security updates on the latest major/minor releases.

| Version | Supported          |
| ------- | ------------------ |
| 0.17.x  | :white_check_mark: |
| < 0.17  | :x:                |

## Reporting a Vulnerability

We take the security of personal financial data seriously. If you discover a vulnerability or security flaw, please report it responsibly so we can address it before disclosure.

### How to Report

1. **Email or Private Advisory**:
   - Send details to `security@savefirst.app` or open a private security advisory on GitHub.
   - Please include:
     - Description of the vulnerability.
     - Steps to reproduce or a proof of concept.
     - Potential impact (e.g., unauthorized data access, privilege escalation).

2. **Response Timeline**:
   - **Initial acknowledgement**: Within 48 hours.
   - **Status update or triage assessment**: Within 5 business days.
   - **Resolution and disclosure timeline**: Coordinated with the reporter after a patch is deployed.

### Safe Harbor

Security research conducted in accordance with this policy is considered authorized. Please refrain from:

- Accessing or modifying personal data belonging to other accounts.
- Executing denial of service attacks.
- Degrading production services or user experience.
